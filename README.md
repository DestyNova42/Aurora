# Aurora ⏰🔒

**FR** — Réveil Android épuré : la sonnerie ne s'arrête qu'avec **votre code ou votre mot de passe**.
**EN** — A clean Android alarm clock: the alarm only stops with **your PIN or password**.

## Télécharger / Download

➡️ **[Dernière version / Latest release](../../releases/latest)** — fichier `Aurora-x.x.apk`.

1. Téléchargez l'APK sur votre téléphone / Download the APK on your phone.
2. Ouvrez-le et autorisez l'installation / Open it and allow installation.
3. Au premier lancement : notifications, affichage plein écran, et désactivez l'optimisation de batterie (Réglages › Fiabilité).

## Fonctions / Features

- Arrêt par code (pavé numérique) ou mot de passe, avec œil pour afficher la saisie
  / Stop with a PIN or password, with a press-and-hold eye to reveal input
- Écran plein écran même verrouillé ; retour, volume et fermeture de l'appli n'arrêtent pas la sonnerie
  / Full-screen even when locked; back, volume keys and closing the app don't stop it
- Volume progressif, volume minimum garanti, répétition, arrêt automatique de sécurité
  / Gradual volume, guaranteed minimum volume, snooze, safety auto-stop
- Sonneries du téléphone ou musique importée / Phone sounds or imported music
- Roues ou clavier numérique pour régler l'heure / Wheels or number pad to set the time
- Français / English selon le système / follows the system language
- 100 % hors ligne, aucune pub, aucun traceur / 100% offline, no ads, no trackers
